# 🃏 One Card Clone

A sleek and interactive clone of the popular *One Card* interface, built with modern web technologies. This project replicates the UI/UX experience of the One Card app/website for educational and demonstrative purposes.



---

## ✨ Features

- 🔐 Login/Signup flow (UI only)
- 💳 Digital Card UI with toggle
- 📊 Transaction history component
- 🎨 Clean, responsive design
- ⚡ Fast and mobile-friendly

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (Flexbox, Grid)
- **JavaScript** (Vanilla / or specify framework like React)
- *(Optional: TailwindCSS, Bootstrap, or any library used)*
